Device Survey

Every nonce in the 32-bit space, hashed on the card, with two things the miner never reads: how often each of the 256 output positions was set, and how many digests carried at least k leading zeros. Every comparison here is integer. A position set c times out of N deviates by exactly 2c − N, and testing it against k sigma is (2c − N)² vs k²N — no division, no square root, nothing that needs a format wide enough to hold it.

The rounding-up in a grid-stride loop was done in thirty-two bits, so nonce_count + stride − 1 wrapped at the top of the range and the trip count came out zero. Every lane exited before doing anything while the host added the full nonce count, so the run returned all-zero counters and reported success. Both columns above are the same code path on the same input — the only difference is the width the addition is done in. A silent zero that reports success is the failure worth being able to recognise, which is why it is drawn rather than described.
