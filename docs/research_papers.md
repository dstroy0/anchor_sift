# Where to start reading

**Purpose:** Name each research paper, what it holds, and how to build it.
**Scope:** `theory/`

The research is twenty research papers under [`theory/`](https://github.com/dstroy0/orior/tree/main/theory), built with XeLaTeX. One command builds all of them:

```sh
sh utils/maint/texbuild/build_theory.sh
```

To read the code instead of the argument, start with [`src/python/README.md`](https://github.com/dstroy0/orior/blob/main/src/python/README.md), then [`src/README.md`](https://github.com/dstroy0/orior/blob/main/src/README.md), then [`examples/README.md`](https://github.com/dstroy0/orior/blob/main/examples/README.md), then [`examples/any_corpus/`](https://github.com/dstroy0/orior/tree/main/examples/any_corpus).

## Theory

### [Salishan](https://github.com/dstroy0/orior/tree/main/theory/theory/Salishan)

_Whose words these are, and how wrong the corpus could be._ The corpus everything in this work is measured against is Salishan speech, written down. This research paper says whose words it holds, how wrong it could be, and what was done to find out.

### [Crystallography](https://github.com/dstroy0/orior/tree/main/theory/theory/crystallography)

_A published cell edge read back off a voxel grid, and whose result that is._ A crystal carries an answer somebody else wrote down before this instrument existed. No other control in this work does.

### [Game Theory](https://github.com/dstroy0/orior/tree/main/theory/theory/game_theory)

_A domain that supplies its own answers, and the reading it corrected._ Games remove the price. A subtraction game's Grundy sequence is eventually periodic, proved, and its period is a quantity a dull exact routine computes by comparison.

### [Particle Physics](https://github.com/dstroy0/orior/tree/main/theory/theory/particle_physics)

_Exactness, discrimination, and the accumulation of matter._ This research paper reads the atom that way: an element is the electrons of its neutral atom, each an integer quantum state, and the whole periodic table is one accumulation of them.

### [Chemistry](https://github.com/dstroy0/orior/tree/main/theory/theory/chemistry)

_The atom as a part, valence as the rule, the bond length as a fact._ Chemistry is that question with the atom as the part. Nothing in this research paper has been measured here. The predictions are on the page before the reader exists.

### [SHA-256](https://github.com/dstroy0/orior/tree/main/theory/theory/cryptography/sha256)

_Where the structure is, where it stops, and how each null was measured._ Measure the null under the same conditions as the effect.

### [Delta Null](https://github.com/dstroy0/orior/tree/main/theory/theory/delta_null)

_Precision Measurement._ Two propositions bound what the search half can do. Soundness is free; the reading is not.

### [Image Transforms](https://github.com/dstroy0/orior/tree/main/theory/theory/image_transforms)

_How a view moves, how what it watches moves, and how to tell them apart._ An object tracked through a sequence of images, in any number of dimensions, is seen through a view that itself moves.

### [The Millennium Problems](https://github.com/dstroy0/orior/tree/main/theory/theory/millennium)

_The corpus, the state of the field, and what this toolkit reaches._ This is reconnaissance and states no result.

### [The Apparatus](https://github.com/dstroy0/orior/tree/main/theory/theory/apparatus)

_The constants, the unit, and the instrument that draws the result._

### [Reading a Boundary](https://github.com/dstroy0/orior/tree/main/theory/theory/boundary)

_What a surface holds, the alphabet that reads it, and where the reading stops._

### [The Instruments](https://github.com/dstroy0/orior/tree/main/theory/theory/instruments)

_What a measurement can see, what it cannot, and how each null was drawn._

### [Precision](https://github.com/dstroy0/orior/tree/main/theory/theory/precision)

_Certificates instead of tables, and the constants nobody checks._

## Thought experiments

### [A Constructed Far End](https://github.com/dstroy0/orior/tree/main/theory/thought_experiments/orior)

_The method applied to ideas._ A reference built from an object's own parts, laid over the object; the delta null idea, of whose three claims two hold and one fails; what a closed boundary holds; and the notebook's testable hypotheses with their tests. The posits with no test are kept as wants in the workbook.

### [The Engine's Ideas, Stated So They Can Be Decided](https://github.com/dstroy0/orior/tree/main/theory/thought_experiments/engine)

Sensor noise, threshold search, state vectors, dwell and entropy, self-reproduction, learned rulesets and identity, each with the test that decides it. The engine's claims with no such test yet are kept as wants in the engine workbook.

### [Cell Lineage from Shape and Whole-Sequence Evidence](https://github.com/dstroy0/orior/tree/main/theory/thought_experiments/cell_tracking)

_A proposal for the Biohub cell tracking task._ Each part is stated with the test that decides it.
