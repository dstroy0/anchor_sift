Certified Twiddle Constants

The twiddle constants of a number-theoretic transform are deployed as unverified literals. A Proth certificate makes each one checkable, deterministically, in two exponentiations, and a composite modulus reproduces a known fault attack with no attacker present.

Douglas Quiggdquigg123@gmail.com github.com/dstroy0September 2026

The contribution

Ravi, Yang, Bhasin, Zhang and Chattopadhyay gave the first fault-injection analysis of the NTT: a single electromagnetic fault zeroizes the twiddle constants, sharply reducing output entropy, enabling key and message recovery against Kyber and existential forgery against Dilithium (ePrint 2022/824). The attack succeeds because no downstream computation distinguishes a valid root of unity from a faulted one — same type, size and range, no error raised.

The contribution here is the provenance argument. Every deployed NTT inherits its modulus and twiddle table as copied literals. Correctness is transmitted, never established, and transmitted correctness cannot report a fault. Proth's criterion turns the check into a certificate that costs microseconds against a transform costing seconds, and the order test that separates a valid root from a same-shape impostor is two exponentiations with no factorisation. The performance figures below are supporting engineering; the argument is the point.

Results

Every figure below was measured on one consumer desktop, using the differencing engine: a single NVIDIA GeForce RTX 3070 (8 GB, 5888 CUDA cores, ~448 GB/s) with an Intel Core i7-5960X (8-core) host and 64 GB RAM, Python 3.14 driving CUDA 13.3. GPU work is the exact number-theoretic transform in 32-bit integer arithmetic; CPU work is Python's arbitrary-precision integers, unbounded in width. The largest operand demonstrated here is the billion-digit product: about 4.3 billion bits, 1.29 billion decimal digits, from factors of ~2.1 billion bits each. No cluster, no cloud, no floating point in the arithmetic path.

The final row is the substantive case. A root whose order merely divides the transform length satisfies the group law exactly — a genuine homomorphism of the wrong group — and every table-level invariant with it. Only the two-exponentiation order test separates them, and no O(n) checksum over the table can.

Method

For N = k·2ⁿ+1 with k odd and k < 2ⁿ, the form every NTT modulus has, Proth's criterion is an equivalence, making a witness a primality certificate. Separately, an element whose order divides 2ᵐ has order exactly 2ᵐ if and only if ω^(2ᵐ) = 1 and ω^(2ᵐ⁻¹) ≠ 1, settling the order in two exponentiations with no factorisation. Both run in microseconds against transform costs measured in seconds.

Nothing here claims a record or a new theorem outside the twiddle provenance argument; the counting-law figure is the classical Gauss circle problem shown as an exact computation.
