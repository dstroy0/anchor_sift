# The theory books

**Purpose:** Find a book of the research, build it, and know which of its chapters are generated and
must be changed through their generator.
**Scope:** every book under `theory/`, `maint/texbuild/build_theory.sh`, which builds them, and
`maint/texbuild/theory_tex.py`, which generates the markdown books' chapters.

## Layout

`theory/` follows the theory_bucket repository's layout, three shelves deep:

- `theory/theory/` holds the finished books.
- `theory/workbooks/` holds the workbooks, one per program.
- `theory/thought_experiments/` holds the thought experiments, kept apart from what was measured.

The books theory_bucket holds are copied from it unchanged. The rest are authored here and sit on the
same shelves: `chemistry`, `game_theory`, `image_transforms`, `particle_physics`, `apparatus`,
`boundary` and `instruments` under `theory/theory/`, and `anchor_sift` under `theory/workbooks/`.
Nothing pulls from theory_bucket automatically.

## Generated chapters

Change these through their generator. An edit to the chapter is lost the next time it is generated.

- `theory/Salishan/chapters/chapter_Salishan_pure_corpus_README.tex`, from
  `maint/data/salishan/hand_extraction/pure_corpus_index.py`.
- `theory/Salishan/chapters/chapter_Salishan_corpus_derivation.tex`, from
  `maint/data/salishan/corpus_derivation.py`.
- `theory/cryptography/sha256/chapters/chapter_sources.tex`, from `tools/book/build_bibliography.py`
  and the citations registry, as its first line records. That tool is not in this tree.
- In each book under `workbooks/` or `thought_experiments/` that holds a `README.md`, every chapter
  whose first line reads `Generated by maint/texbuild/theory_tex.py`, from the markdown file that
  line names. `chapters/order.tex` lists them with the README first and the rest in the order the
  book's README names them.

## Building

```sh
sh maint/texbuild/build_theory.sh [<book> ...]
```

A book is named by its path below `theory/`, as in `theory/delta_null`, `workbooks/engine` or
`theory/cryptography/sha256`. Output goes to `build/theory/<book>/` and nothing is written beside the
source. A figure a chapter includes from `build/theory/figures/` is reached by a relative path from
the book's directory, and that path counts the book's depth below the repository root.
