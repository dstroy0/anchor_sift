\chapter{Round count as depth}

This chapter specifies an experiment measuring how fast the interior stops reaching the boundary as a function of how many rounds it passed through, and where that curve crosses below the detection floor.

\textbf{This chapter specifies work and does not report it.} Everything below is a design. The observables, the compression truncated at an arbitrary round and the driver are not implemented, and no curve is measured. A specification written down before the run is the only kind that can be checked against the run afterwards.

\section{The idea in one line}

The boundary readings measure information reaching a surface as a function of depth, and find it falls as \((r/R)^l\). Here depth is the round number. The question is the same one: how much of the input reaches the output, measured against how far in it started.

\section{Why this is the right question and breaking it is the wrong one}

A break needs a boundary observable departing from flat by more than sample noise, at full rounds. The strict avalanche~\cite{src:Webster-and-Tavares-1986}, bit bias and Rényi~\cite{src:Renyi} observables read flat at full rounds. Linear~\cite{src:Matsui-1994} and differential~\cite{src:Biham-and-Shamir-1991} cryptanalysis reach part of the way. Thirty-one steps is the collision record~\cite{src:Mendel-Nad-and-Schlaffer-2015}, with a colliding pair found in practice~\cite{src:Li-Liu-Wang-Dong-and-Sun-2024}. Other attacks reach further: second-order differential collisions on reduced SHA-256~\cite{src:Biryukov-Lamberger-Mendel-and-Nikolic-2011}, semi-free-start collisions at \(39\) steps~\cite{src:Li-Liu-and-Wang-2024}, and biclique attacks at \(45\) steps for preimages and \(52\) for pseudo-preimages~\cite{src:Khovratovich-Rechberger-and-Savelieva-2012}. None reaches \(64\). Hunting the full-round hole is hunting a thing the observables already read as absent.

Measuring the decay is different. Reduced rounds leak, and the leak is not written down as a curve in the depth variable with a detection floor drawn on the same axes. That curve is a real result. It quantifies the difficulty instead of asserting it, and it makes a falsifiable claim: the leak at round \(k\) is this size, and here is where it falls under what this many samples can see.

\section{What is measured}

Run SHA-256~\cite{src:FIPS-180-4} truncated at \(k\) rounds, for \(k\) from \(1\) to \(64\), and read a boundary observable at each.

\textbf{Strict avalanche.} Flip one input bit, count how often each output bit flips, over many inputs. A flat function sits every counter at half the sample size. The departure from half, summed across output bits, is the leak.

\textbf{Bit bias.} How far each output bit's one-rate departs from half.

\textbf{Collision entropy of the output byte histogram.}

Each returns a single number per round count. The run is one curve per observable, \(64\) points each.

\section{The detection floor, drawn on the same axes}

A bias of size \(b\) needs about \(1/b^2\) samples to see above the noise. At a flat function one counter's rate over \(N\) samples has standard deviation \(1/(2\sqrt{N})\). The strict avalanche observable sums \(|\text{departure}|\) over \(M\) counters, and that sum has a null mean of \(M\sqrt{2/\pi}/(2\sqrt{N})\), \(M\) times the mean of a half-normal. That floor is a horizontal line on the same plot as the decay curve, and where the curve crosses under it is the round count past which this run cannot tell the function from flat.

The floor is not a nuisance to be hidden. It carries the result: it says what was in reach of this much compute, and a later run with more samples can lower the line and show the curve continuing underneath, or show it genuinely flattening.

\section{The arithmetic}

The decay spans many orders of magnitude, from a large leak at a few rounds to nothing measurable at full rounds. The counts are integers. A 64-bit counter holds them exactly to \(1.8 \times 10^{19}\), where single precision holds every integer exactly only up to \(2^{24}\). With integer counters the curve stays a curve down to where sample size and not arithmetic stops it, and measuring the decay is kept separate from measuring a floating-point floor.

\section{What each outcome would mean}

\textbf{The curve falls smoothly and crosses the floor around the round count cryptanalysis already reaches.} The expected result. It turns the known reduced-round weakness into a measured decay rate and puts a number on the margin.

\textbf{The curve has a step, a shoulder, or a bump that does not fall.} A round range where more structure survives than the smooth decay predicts. That is where a cryptanalyst would look, and the measurement would have pointed at it instead of guessing. Almost certainly it will not happen at full rounds, and the experiment would show it if it did.

\textbf{The curve is already under the floor by a few rounds.} The samples were too few. Lower the line with more samples and run again. Nothing is concluded from a curve starting under its own floor, and a run passes that check before its flat tail means anything.

\section{What this does not claim}

It does not claim a break, a bias at full rounds, or a shortcut to a preimage. It claims a measurement: the leak as a function of depth, with the floor saying how far down the measurement could see. A flat tail under a floor is not evidence the function is flat there. It is evidence the run could not see a leak that small, a statement about the run and not about SHA-256.

\section{What has to be built}

A compression function that stops at an arbitrary round \(k\), the three observables computed on it, a driver collecting one curve per observable with a round-count parameter, and a plot carrying the floor as a second series.
