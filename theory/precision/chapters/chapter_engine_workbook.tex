\chapter{The engine workbook}

\textbf{Purpose:} Record every configuration the engine has been run in, what was claimed of it, what would have refuted the claim, and what settled it. \textbf{Scope:} the arithmetic, the moduli, the machine, the cost, and the objects the engine has been pointed at.

\textbf{Status:} not formal theory. Everything below is measured and repeatable. None of it has been examined for inefficiency or absurdity, and several entries record the implementation as the thing measured.

\section{The schema}

Every entry carries five fields.

\begin{center}
\begin{tabular}{@{}ll@{}}
\toprule
field & what it holds \\
\midrule
Category & which class the entry belongs to \\
Hypothesis & one sentence, stated so it can be wrong \\
Configuration & every parameter needed to re-run it, none implied \\
Refutation & the result that would have killed it, written before the verdict \\
Proof & what was run, what came back, which way it settled \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Refutation is written before the proof.} A hypothesis with no refutation absorbs any result, because nothing was excluded in advance. Every entry below that cost a session to find was found by a claim stated sharply enough to be caught wrong.

\textbf{Configuration is complete or the entry is worthless.} The engine has twice been wrong about which machine it was running on. Both times a parameter was implied instead of written.

Identifiers are \texttt{E-\textit{category}-\textit{number}}, assigned once. A refuted entry keeps its number and gains a verdict. Nothing is deleted, since a record of what failed prevents it being retried.

\section{Standing constraints}

These bound every entry and are not re-argued in each.

\textbf{The search is precision bound, not time bound.} A relation whose coefficients run to \(D\) digits cannot be seen below roughly \(D \cdot n\) digits of input, because the lattice cannot separate a true relation from an accidental cancellation there. Depth is the only axis with no floor under it.

\textbf{A device multiply beats the host only above 1,024 limbs}, which is \(32{,}768\) bits. Below that a device call is mostly pipe. Measured on one host and one card, and it moves with either.

\textbf{The degree one region is closed.} Borwein, Galway and Borwein proved in 2004 that \(\pi\) has no degree one BBP formula in a power of two base beyond the three known. Searching it returns what is already there, so it appears below only as a control.

\textbf{A candidate is not a discovery.} Surviving the screen shows only that a relation is not a precision artifact. Most of the searched space is already mapped, and a surviving relation has still to be checked against the compendium.
