% WHY THIS BOOK SITS OUTSIDE theory/held/
%
% Douglas narrowed the partition rule on 2026-09-11: "dont include any advantage research, that gives
% away our advantage. precision fair." The advantage is what the engine is pointed at and what was
% found by pointing it. The precision work is the engine itself, and general-purpose arithmetic does
% not reveal its target.
%
% Nothing in this book names SHA-256, a block header, a pool, a nonce or a corpus. It is number
% theory and the arithmetic under it: Proth certificates, the order of a root of unity, the group law
% on a twiddle table and the counterexample showing that law is not sufficient.
%
% Douglas has since confirmed the clearance directly, and theory/PARTITION.tsv classes this book
% EXTERNAL: cleared for publication and not yet out.
%
% THE TEST A CHAPTER HAS TO PASS TO BE IN THIS BOOK
%
% Not "what can be removed". Douglas's own argument settles that: cutting obvious steps out of a
% publication fools nobody who works in the field and insults everyone who does not. So the test is
% whether what remains is a WHOLE SUBJECT. A chapter that cannot stand without a held piece does not
% go in hollow, it does not go in.
%
% THE UNIT OF WORK DECIDES A BENCHMARK, and it is mechanical rather than a judgment made afresh each
% time. A figure is fair when its unit is an ARITHMETIC operation and held when its unit names a
% DOMAIN operation. Read the units off the sentence:
%
%   fair    a 1,290,000,000-bit product in 1.72 s of device time
%           pi to 10,000,000 digits in 116.5 s
%           the relation search costing precision^2.64
%
%   held    "2.15 trillion SHA-256 evaluations summarised in 3 MB of counters"
%           "26.6 billion multiply-accumulates in 3.2 s", which is a Gram matrix for a permutation
%           null and therefore the held work's own instrument wearing an arithmetic unit
%
% That second held line is the dangerous shape. It reads as pure throughput and the work it counts
% is not, and it sits one sentence away from a fair figure in every draft.
