\section{\texorpdfstring{Phase A: the vocabulary, once, used by everything below}{Phase A: the vocabulary, once, used by everything below}}

Doug's rule for everything: truthy and falsy vector magnitudes, by which the machine steers itself iteratively. Every verdict is a field, zero false and nonzero true; AND is PRODUCT, OR is SUM, NOT is 1 − |COMPARE(t, 0)|, and a value is gated by PRODUCT(value, t). No thresholds and no host decisions: a pass writes its verdicts as records, and the next pass reads them.
