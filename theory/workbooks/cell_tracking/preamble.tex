% FALLBACK. Charis does not carry Greek outside the IPA letters, box drawing, or most of the arrows
% and operators the tables print. Under LuaLaTeX a luaotfload fallback chain handed those to DejaVu.
% XeTeX has no fallback chain. It has character classes: a character is put in a class, and a token
% list runs where a run of that class begins and where it ends. The list here opens a group and
% switches face, and the closing list ends the group.
%
% Three rules keep the classes from damaging the text around them.
%
%   Only characters Charis lacks are classed. A class boundary ends XeTeX's shaping run, and a
%   combining mark shaped apart from its letter lands beside it. Charis's own Greek, the IPA theta,
%   chi and beta among it, is never classed, and neither is any combining mark.
%
%   The switch fires from every face except DejaVu Sans and DejaVu Sans Mono, which already carry
%   the Greek, the boxes and the arrows. Switching there would replace a face that was correct.
%   The test is by exclusion because Charis appears under more than one family name: classicthesis
%   letterspaces its headings with \addfontfeature, which makes a new family, and a capital sigma in a
%   chapter title was dropped while the test asked for the main family by name.
%
%   A character no face here carries still fails the build. \tracinglostchars puts every one in
%   the log as "Missing character", and build_theory.sh counts them.
%
% The ranges are Charis 6.101's character map subtracted from ten Unicode blocks (Greek, the arrow
% blocks, the operator blocks, technical, box drawing, block elements, geometric shapes), split by
% which DejaVu face has the glyph. They were computed from the font files. A range naming a
% codepoint Charis carries would pull that letter out of its word.
%
% The monospace class holds U+02FD, the modifier letter shelf the oracle pages mark a space with,
% and U+200B. DejaVu Sans Mono carries neither and Charis carries both. The Salishan book dropped
% the shelf six times under the old engine and still built. The shelf switches to Charis only
% where it is set in the monospace face.
\tracinglostchars=2

% Each entry opens a group and switches face only where the rules above allow it, and records
% whether it did. \theory@leave closes exactly what was opened.
\let\theory@leave\relax
\newcommand*\theory@open[1]{\begingroup\global\let\theory@leave\endgroup#1}
\newcommand*\theory@stay{\global\let\theory@leave\relax}
\newcommand*\theory@unlessdejavu[1]{%
  \edef\theory@here{\f@family}%
  \edef\theory@sf{\sfdefault}%
  \edef\theory@tt{\ttdefault}%
  \ifx\theory@here\theory@sf
    \theory@stay
  \else\ifx\theory@here\theory@tt
    \theory@stay
  \else
    \theory@open{#1}%
  \fi\fi}
\newcommand*\theory@onlymono[1]{%
  \edef\theory@here{\f@family}%
  \edef\theory@tt{\ttdefault}%
  \ifx\theory@here\theory@tt
    \theory@open{#1}%
  \else
    \theory@stay
  \fi}

% 4095 is XeTeX's boundary class: the start or end of a run of characters, at a space, a brace or
% a box edge.
\newcommand*\theory@switch[2]{%
  \XeTeXinterchartoks 0 #1 = {#2}%
  \XeTeXinterchartoks 4095 #1 = {#2}%
  \XeTeXinterchartoks #1 0 = {\theory@leave}%
  \XeTeXinterchartoks #1 4095 = {\theory@leave}}

% percent of every page is blank, which is a page design for a printed thesis read at a desk with a
% pencil. These books are read on a screen and posted to an archive.

% the line runs past what is comfortable to read at 11pt; narrower and the longtables in the workbook
% and the reproductions chapter start breaking columns they currently fit.
%

% reserved for a feature none of them use.
